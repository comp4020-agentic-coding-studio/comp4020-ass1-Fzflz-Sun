About this model

This is a simplified teaching model, not driving instruction. One car, one broad fixed corner, symmetric front/rear load, and a linear tyre model with a friction-circle limit per axle. Steering, throttle, and braking all draw on the same per-axle grip budget; drivetrain only changes which axle carries the longitudinal share — FWD does not always understeer, RWD does not always oversteer, and AWD can still slide if pushed hard enough. Dry/wet/ice are a relative, illustrative grip ordering, not measured coefficients for any real tyre or surface. There is no real-time driving input by design: steering is a fixed autosteer program calibrated to whichever track you pick (the same every run for that track, so it isn't a second variable alongside drivetrain/surface), and throttle intensity/timing/track are the settings you choose before pressing Run. Every track has a finite, calibrated length; a run finishes when the car reaches the end of it. Full assumptions and tuned constants are documented in this project's docs/model-assumptions.md.
